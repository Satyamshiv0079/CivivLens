# CivicLens Frontend

The user-facing web interface for CivicLens, built with React, Vite, TypeScript, and Tailwind CSS.

## Features
- Clean component architecture
- Leaflet map integration for geographic issue tracking
- Responsive mobile-friendly UI using Tailwind CSS
- Real-time backend connectivity check

## Scripts
- `npm run dev`: Start local Vite development server on port 5173
- `npm run build`: Type-check and compile frontend bundle
- `npm run preview`: Preview production build locally
